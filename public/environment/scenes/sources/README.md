# Anass — World Scenes V1

Pack de 18 images fournies pour le moteur de monde immersif du portfolio.

- `01-primary/` : 10 scènes à utiliser en priorité pour la V1 du monde vivant.
- `02-optional/` : 8 scènes secondaires ; ne pas forcer leur utilisation si elles cassent la cohérence ou si le crop est mauvais.
- `scenes-manifest.json` : dimensions et orientation de chaque source.

## Règles

1. Conserver les sources originales intactes.
2. Ne pas générer de nouveaux paysages à partir de ces images.
3. Créer les versions web optimisées dans le repository (`AVIF/WebP`) sans écraser les sources.
4. Le hero doit rester ancré sur la scène montagne actuelle avec le rocher + DJI Goggles 3 + DJI Avata 2 + DJI FPV Remote Controller 3 au premier plan.
5. Les autres scènes servent au voyage continu du monde derrière le site.
6. Les images verticales sont optionnelles et ne doivent être utilisées que si le cadrage desktop/mobile reste convaincant.
7. Plusieurs images contiennent déjà un soleil visible : ne pas ajouter un deuxième disque solaire. Dans ces scènes, le moteur solaire doit piloter la lumière, la chaleur, l'intensité, le voile et l'atmosphère plutôt qu'inventer un nouveau soleil mobile.
